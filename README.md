# ZeroDrop 🏸

Wear OS 独立羽毛球计分应用。专为解决球场上"记不清比分、忘了谁发球、站错半区"的痛点而设计。

## 为什么需要 ZeroDrop？

打羽毛球的人都知道这些尴尬时刻：

- **"刚才几比几了？"** — 对抗激烈时大脑 CPU 全给了步伐和击球，比分早忘了
- **"该谁发球？站左边还是右边？"** — 每次停下来的灵魂拷问
- **"没带手机，手环能计分吗？"** — 不想带手机上场，手表又没趁手的计分 app
- **"误触退出比分全没了"** — 大部分同类 app 不支持中途退出保护

ZeroDrop 解决的就是这些：**抬腕即看比分，清黑白操，退出了也不丢数据**。

## 核心特点

### 极简视觉 — OLED 纯黑省电
屏幕几乎全黑，只显示两个分数 + 一条发球指示线。充分利用 Wear OS OLED 屏幕特性，省电又清晰。

### 盲操交互 — 不看屏幕也能计分
- **点上半屏** → 己方得分
- **点下半屏** → 对方得分
- **长按 1.5 秒** → 进入编辑模式（修改比分 / 撤回 / 新比赛）

不需要盯着手表找按钮，运动中凭手感就能操作。

### 发球站位自动计算
零思考——系统根据发球方的得分自动判断该站在左半区还是右半区，绿色/蓝色指示条一眼就懂：
- 发球方得分偶数 → 右半区发球（口诀：**0 分在右边**）
- 发球方得分奇数 → 左半区发球

### 换边提醒
每局结束自动弹窗提示换边；决胜局中途达到半场分数时额外提醒一次。确认换边时有震动反馈。

### 状态持久化
每次计分自动落盘。手环死机、杀后台、没电——重启后比赛进度自动恢复，零丢失。

### 灵活赛制
- 单局制 / 三局两胜可选
- 计分上限 11 / 15 / 21 分可选
- 支持局中编辑比分、撤回操作

### 适配圆形和方形手表
UI 尺寸根据屏幕大小自动缩放，不会在圆形表盘上切掉边缘内容。

## 构建与运行

1. Android Studio (Hedgehog+) 打开项目
2. 选择 Wear OS 模拟器或真实手表
3. Run

```bash
./gradlew assembleDebug
```

## 计分规则

- 每局先到上限分且领先 2 分者胜，30 分封顶
- 每局结束时自动换边；三局两胜制下决胜局到达半场上限时额外换边一次
- 发球站位：只看发球方自己分数，偶数站右（口诀：**0 分在右边**）、奇数站左
